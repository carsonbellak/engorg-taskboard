# ipc/ — main-process handler notes

Each module: `module.exports = function register(getMainWindow) { ipcMain.handle('ns:verb', …) }`, registered in `main.js`, exposed in `preload.js` (**grep preload.js for exact channel names/signatures**). Everything here is desktop-only — no PWA mirror, unless you also add renderer UI with a PWA equivalent. Secrets: encrypt with `safeStorage`, decrypt only in main, never return them to the renderer.

## Non-obvious handler semantics

| Module | Notes |
|--------|-------|
| `data.js` | `data:load/save` restricted to `ALLOWED_FILES` (see root CLAUDE.md). Also `shell:openExternal/openPath`, `dialog:openFiles`, `installer:build`. |
| `files.js` | `files:readText` caps at 50 MB; `files:delete` moves to trash; `files:writeText` auto-creates dirs; `files:watch` fires `files:changed` on the main window; KiCad SVG/GLB export via kicad-cli (`files:hasKicadCli`). |
| `git.js` | Shells out to system `git` (no native deps). Network ops run with `GIT_TERMINAL_PROMPT=0` (auth = OS credential manager). `dirPath` = repo working dir; `*Paths` arguments are **repo-relative**. `git:status` flags `conflicted:true`; `git:mergeStatus` reads the git dir for MERGE_HEAD etc.; `git:continueOp` uses `GIT_EDITOR=true`; `git:diffPath` shows untracked files via `--no-index`; `git:raw` tolerates a leading `git`. Folder workflows: `uploadFolder`/`publishFolder`/`extractFolder`/`sparseDownload` (temp clone auto-cleaned). |
| `calendar.js` | `calendar:fetchFeed(url)`: asks a linked Pi's feed cache first (`piLink.fetchFeed`), otherwise fetches locally. Parsing and fetching live in **`core/ics.js`** (Electron-free, shared with the Pi). `normalizeIcs` is re-exported here; **all ICS parsing goes through it**, including `email.js` invite scanning. |
| `pi-link.js` | Raspberry Pi companion client (see `pi/CLAUDE.md`). `pi:discover` (UDP broadcast to `core/pi-protocol` ports) / `pair(host,port,code)` / `unpair` / `status` / `update` / `setAutoUpdate` / `printerJobs(since)`. Token is encrypted with `safeStorage` in `appdata/pi_link.json`. Exports `fetchFeed`/`printerUrl`/`isLinked`, all failing soft to `null` with a 2-min back-off. Registers `moonraker.setRemoteResolver(printerUrl)`. `syncVersion` (15 s after launch, then every 6 h) pushes `{printerEnabled, printerSeed, timezone}` and asks an older Pi to self-update. A Pi that moved IP is re-found by `id`. |
| `outlook.js` | Reads Outlook calendar via PowerShell COM. **Registry guard first**: with no mail profile, COM pops an unsuppressible "Create New Profile" dialog, so it returns `[]` instead. |
| `email.js` / `oauth.js` | IMAP (imapflow) + SMTP (nodemailer), one pooled IMAP connection per account; app passwords in `safeStorage`. `oauth.js` = Microsoft auth-code + PKCE public-client flow (child window intercepts loopback redirect) → XOAUTH2; refresh token encrypted. |
| `claude.js` | User's own Anthropic API key (`safeStorage`). `claude:extractSyllabus` → structured `{ course, events }` for `renderer/syllabus-import.js`. Roadmap for more AI features: memory claude-ai-integration. |
| `auth.js` | `auth:googleSignIn` — child window to the hosted auth page, polls for `{ idToken, accessToken }`. Firestore itself is renderer-only. |
| `printer.js` | Moonraker proxy (`apiGet/apiPost/uploadFile/uploadFileData`), `webrtcOffer` (SDP), `sendCameraFrame` (feeds Fluidd), `setEnabled` (starts/stops the Fluidd server). Use `state.moonrakerUrl` (DHCP self-heal in `moonraker.js`: health check → linked Pi's known URL → LAN /24 scan). |
| `slicer.js` | OrcaSlicer CLI: **never exits on Windows** — poll output-file stability, then kill. `mergeUserProfile()` merges user profiles (missing `type`) with their system base into a temp file. Returns `estimates { time, filamentMm, filamentG, filamentM, fileSize }`. |
| `print-history.js` | `printHistory:archive` copies STL + G-code into `appdata/print_archive/<id>/`; `openArchive`. |
| `kicad-importer.js` | Port of `kicadImporter.py`. Stages: `extractZips` (dependency-free unzip via `tar`/`Expand-Archive`), `digikeyLookup` (OAuth2 client-credentials, global `fetch`), `addStepFile`, `writeLibrary` (regex s-expr edits). Creds: `config.js` defaults or `settings.json` override. |
| `utility-store.js` | Catalog JSON from `UTILITY_STORE_CATALOG_URL` (`{ utilities: [{ id, name, icon, description, version, entry }] }`); downloads HTML to `appdata/utilities/<id>/`. Remote utilities run in a sandboxed iframe — **never** with app privileges. |
| `engink-mirror.js` | LAN WebSocket server (`ws`, port 8770) + UDP discovery responder (`dgram`, 8771) answering the tablet's broadcast with `{name,port,code}`; a 6-digit code gates connections. Forwards messages (`open`/`page`/`wet`/`wetClear`/`view` + synthetic `server`/`client`) on `engink:message`, status on `engink:status`. Lives on `state.enginkMirror`; started on demand, stopped on quit. Tablet side: `mobile-ink` `MirrorManager`/`MirrorClient`. |
| `file-merger.js` | Only the native dialogs: `selectFiles` (PDF+image filters) → `[{name,path,ext,size}]`; `save(bytes, defaultName)` writes + opens. Assembly is in the renderer (needs canvas). |
| `ftdi.js` | FTDI bit-bang for the UART Bridge via a long-lived Python helper (`ftdi_helper.py`, ftd2xx), one JSON command per line on stdin/stdout. Native Node FTDI bindings are avoided on purpose (Electron rebuild pain). |
| `uart-programs.js` | UART visual programs as JSON in `appdata/uart_programs/`; Python export/import carries an embedded model header so it round-trips losslessly. |
| `wifi-checker.js` | Port of a PyQt5 tool: Excel input, `netsh` connect, IP discovery (arp + ipconfig CIDRs + optional nmap), ping, SSH. |
| `spell.js` | Offline checker: lazy-loads `renderer/lib/words-en.txt` (~370k words) into a Set; Norvig-style suggestions; user dictionary `appdata/spell_user.json`. Chromium's checker is disabled (`webPreferences.spellcheck:false`) to avoid double underlines. |
| `os-theme.js` | Themes Windows itself (reversible, Windows-only): accent colour + dark/light (`ColorPrevalence` kept OFF so Start/taskbar aren't flooded). **Tinted** (`apply` with `payload.tint {bg,header}`) turns prevalence ON, but with deep, luminance-capped theme shades (`tintColors`) for Start/taskbar (crStartColor) and title bars (DWM AccentColor), never the raw accent. Each apply writes `appdata/os_theme_last.json` (diagnostic). or full contrast theme (`applyContrast`, unwired, still PowerShell); `restore`. Accent/restore/snapshot are **native via koffi** (registry + user32). The registry is only a cache, so the live accent is pushed with uxtheme `SetUserColorPreference` (**ordinal #122**; #120 = named `GetUserColorPreference`). Slow calls run via `.async`. Ops are serialised (a newer apply supersedes queued ones) and emit `osTheme:progress {op,pct,label}` → the renderer's progress popup. Restore only re-toggles high contrast / rewrites system colours if they differ, because either forces every app to repaint. See memory windows-os-theming. |
| `window.js` | Titlebar controls + `appmenu:action`. Acts on the **sender's** window (main or desktop-mode window); ignores minimize/maximize/fullscreen when `win._desktopMode`. |
| `updates.js` | Compares the install with `CONTRIB_REPO` (git HEAD vs upstream if `.git` exists, else blob-SHA diff); also `currentVersion` (`app.getVersion()`) vs upstream `package.json` → `versionBehind`. `updates:restart` relaunches with `--relaunched`. |
| `release.js` | Owner-only in-app release (Settings → About): `release:info` checks GitHub identity vs `CONTRIB_REPO.owner`; `release:cut` runs the same root `release.js` pipeline. |
| `contribute.js` | Submit local changes as a PR with no local git: blob-SHA diff vs the upstream tree, fork + single commit via the GitHub git-data API, GitHub device sign-in. |

## Desktop mode (`desktop-mode.js`, Windows-only)

The main window acts as the Windows desktop (Settings → General). FFI via **`koffi`** (user32/kernel32, no native build). State is **main-owned** in `appdata/desktop_mode.json` `{ enabled, separate }` — device-local, never written by the renderer.
- Stays a normal **top-level** window (input/DPI/acrylic intact) whose **owner** is `Progman`, parked at `HWND_BOTTOM`, sized to the primary **work area**. A `hookWindowMessage(WM_WINDOWPOSCHANGING)` z-lock ORs in `SWP_NOZORDER` (validated against the WINDOWPOS's own hwnd) so clicking focuses without raising.
- 400 ms poll: lifts above the desktop when Win+D makes Progman/WorkerW foreground, drops back when an app takes focus, re-owns after an Explorer restart; undoes minimize. **Ctrl+Alt+D** (global, only while active) turns it off. Sets `win._desktopMode`.
- **"Keep a normal window too"** (`separate`): a second window (`createDesktopWindow` in `main.js`, `index.html?embedded=1&desktop=1`, off the taskbar, skips background services) becomes the desktop; closing the main window then only hides it; closing the desktop window turns the mode off.
- `desktop:changed(active)` → `titlebar.js` toggles `body.desktop-mode-active` (hides `.titlebar-controls` and `#split-winctrls`).
- ⚠️ **Do not re-parent into WorkerW/Progman** (`SetParent`, the Wallpaper Engine trick) — the icon view eats all input, and `GetParent()` returns 0 for a re-parented non-`WS_CHILD` window. (That was v1; it failed.)
- ⚠️ Electron implements `resizable:false` as min = max = current size — **size the window before locking it**.
- User setup: Win11 with Progman hosting SHELLDLL_DefView directly (no WorkerW); primary monitor only.

## Integrations (linked accounts → projects + assignment notes)

New one → `/new-integration` (the `integration-builder` agent follows this template). Shared pattern:
- **Main** (`ipc/<name>.js`): `status` (never returns secrets) / `connect` / `disconnect` / `fetchAssignments` → `{ events: [schedule-item shape + courseId/course/courseShort/assignmentId/dueISO/submitted], courses: [{ id, name, short, count }], coursesScanned }` or `{ error, events: [] }`. Metadata file in `appdata/<name>.json`.
- **Renderer** (`app.js` `sync<Name>`, startup + every 30 min): **one project per class** (linked by an id field on the project, **merged by normalized course code** with any other platform's project for the same class) + **one `category:'assignment'` note per assignment** (`task.source`, `task.<name>Id`, an "Open in …" note link). **Priority recomputed every sync** from time-to-due (>1 wk Low / ≤1 wk Medium / ≤24 h High). Submitted/completed → **marked done, never auto-un-completed**. Course names have the term prefix (`Fall 2026`…) stripped.
- **The note's `dueDate` IS the calendar entry** — no `scheduleItem`. Sync step 4 calls `importExternalEvents([], { source:'<name>', prune:true })` only to purge duplicates from older versions.
- Brand logo via `sourceLogoSvg` (`renderer/components/sticky-note.js`, mirrored in `pwa/app.js`). Projects/notes reach the PWA via Firebase for free; downloaded files stay device-local.

**Gradescope** (`gradescope.js`) — no API, so it posts the login form (CSRF token + `session[email]`/`session[password]`) via Electron `net.fetch` on a dedicated in-memory session partition (cookie jar survives the redirect chain); `ensureAuth` caches the login ~40 min. Scrapes dashboard course boxes + each `#assignments-student-table` (or React `data-react-props`). Password in `safeStorage` (`appdata/gradescope.json`). Projects linked by `project.gradescopeCourseId`; it also stores `project.courseShort`/`courseCode` so Brightspace can merge. `gradescope:fetchAttachments(courseId, assignmentId)` best-effort downloads to `appdata/gradescope_attachments/<assignmentId>/` (device-local): fetches `/submissions/new` — the template PDF URL is in a **`data-template-url` attribute**, not the empty anchor href; allowlisted coursework extensions only, only from gradescope.com / its S3+CloudFront CDNs, no executables, ≤30 MB. Renderer calls it lazily once per note (`fetchGradescopeAttachments`, guarded by `task.gsAttachVer`).

**Variate** (`variate.js`) — Purdue StudioKit. Real JSON API but gated by **Purdue SSO (BoilerKey + Duo)** via OAuth/PKCE, so **no headless login and no stored password**. `variate:connect()` (no args) opens `VARIATE_APP_URL` in a visible BrowserWindow on partition `persist:variate`; the user completes SSO once. Each fetch reopens it **hidden** — while the SSO session lives the SPA re-auths silently — reads the SPA's bearer token from its own `localStorage` (`persist:auth`) and calls the API **from inside the page** (CORS-allowed): `/api/groups/home`, `/api/groupAssessments` (`startDate/endDate/dueDate/currentLearnerStatus` ∈ UNSTARTED/SUBMITTED/COMPLETED/ENDED), `/api/assessments` (names), `/api/account/userInfo`. Effective due = `dueDate || endDate`. Session expired → `{ needAuth:true }` → renderer shows "reconnect". `appdata/variate.json` holds only name/email/connected. Projects linked by `project.variateGroupId`.

**Brightspace** (renderer only, no IPC) — `app.js` `syncCalendars` → `syncBrightspaceNotes(events)` turns ICS entries whose SUMMARY ends in **"- Due"** into assignment notes (`source:'brightspace'`, `brightspaceId`); "- Available" entries are ignored. The **course is the event's `LOCATION`** (e.g. `Fall 2026 ME 164 - LAB`), matched via `courseCodeOf` (pads 3-digit → 5-digit so `ME 164` ≡ `ME 16400`). The first calendar sync is delayed ~16 s so Gradescope populates course codes first. Note-backed deadlines get `ev._noteBacked` and are filtered out of the schedule import; other Brightspace events import normally. **Cannot auto-complete** — the public ICS feed has no submission data (would need a D2L login/Valence API integration, not built).

**GitHub** (`github.js`) — PAT in `safeStorage` (`appdata/github.json`), validated via `/user`. `github:fetchActivity(days=90)` → commits on **owned** repos → `app.js` `syncGitHub` caches them in `settings.gitActivity` (+ `gitLastSync`) for the Timeline.
