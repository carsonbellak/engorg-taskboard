# renderer/ — module notes

Everything here is a **global** loaded by `<script>` tags in `index.html` (order matters, no imports/modules). Shared globals: `dataManager`, `viewRenderer`, `modalManager`, `firebaseSync`, `engineeringUtilities`; helpers `escapeHtml`, `assignRainbowColors`, `resolveAutoColor`, `formatDateShort`, `isOverdue`, `getStickyColors`; constants `DAYS`, `PRIORITY_COLORS`, `CATEGORY_LABELS`, `PROJECT_CATEGORY_COLORS`, `APP_CATEGORIES`/`DEFAULT_CATEGORIES`.

**Parity:** a user-facing change here must land equivalently in `pwa/app.js` / `pwa/styles.css` (see root CLAUDE.md; class translations in `.claude/parity-map.json`). Desktop-only modules are marked below.

Linked-account sync loops (`syncGradescope`, `syncVariate`, `syncCalendars`/`syncBrightspaceNotes`, `syncGitHub`) live in `app.js`; their full behavior is documented in `ipc/CLAUDE.md` § Integrations.

## Views & Navigation (`app.js`)

- **Interface mode** (`window.applyUiMode`, `settings.uiMode` `'tabbed'`|`'organic'`, Settings → General → Interface): `body.organic-mode` hides `.header-tabs`/`#btn-tab-lock` and the Ecosystem tree *is* the app (create data by right-clicking a branch; the gear stays to switch back).
- **Header tabs** (`.header-tab[data-view=…]`) map to `#view-<name>`: `notes`, `projects`, `ecosystem`, `calendar`, `email`, `timeline`, `timers`, `board`, `purchasing`, `stats`, `files`, `engineering`. `viewRenderer.currentView` tracks the active one; `renderCurrentView()` dispatches. Tabs are hide-/reorderable (`hiddenTabs`/`tabOrder`/`hotbarUtilities`; `MAIN_TABS` in `settings.js`).
- **Sidebar = project filter.** `viewRenderer.selectedProject` is `'all'`, a project id, or `'all-archived'`. "All Projects" is a pure filter — it does **not** switch views. `viewRenderer.selectedDay` still exists (default day for new notes + progress bar) though the sidebar day picker is gone.
- **Projects tab** — `ViewRenderer.renderProjectSlates()` renders one slate per project into `#view-projects`, sectioned by `projectGroups` then "Ungrouped"; "+ Group" toolbar button; ••• per group (Edit/Archive/Delete). Clicking a slate drills into that project's Notes. "All Archived" reuses this tab (archived-group sections offer **Unarchive group**).
- **Project groups in the sidebar:** `#btn-add-group`, collapsible `.sidebar-group` headers, ••• menus via `#modal-group`. Assign by **drag** (group header/body/ungrouped zone) or project ••• **Move to**. After any sidebar drag, `commitSidebarOrder()` rebuilds `dataManager.projects` order + each `groupId` from the DOM.
- **Group actions are centralized** in `app.js` (`editGroupFlow / archiveGroupFlow / deleteGroupFlow / unarchiveGroupFlow`) driven by `window` CustomEvents (`add-group`, `edit-group`, `archive-group`, `delete-group`, `unarchive-group`) — sidebar and Projects page share that path. Group CRUD lives in `data.js` (`addProjectGroup / updateProjectGroup / deleteProjectGroup / setProjectGroup / getProjectGroups / getActiveProjectGroups / archiveProjectGroup / unarchiveProjectGroup`; `getActiveProjectGroups()` = `!archived`).
- **PWA mirror of groups:** `<optgroup>`s in the PWA's project `<select>` (`projectOptionGroups()` in `pwa/app.js`). The PWA has no projects-overview view.

| `handwriter.js` | `handwriter` — LaTeX → handwriting in the user's own font (default `Carson Hand`, loaded by name via `FontFace(local(...))`, never bundled) on EngInk-style 816×1056 pages. Own LaTeX parser (preamble/macros/sections/lists/`\maketitle`) + TeX-like math box layout; strokes the font lacks (fraction bars, radicals, stretched delimiters, arrows, accents) are drawn as ink strokes (`inkStroke`). **Letters are re-written with the pen, not pasted** (user feedback: warped bitmaps looked distorted, textured ink looked scratchy — they write with a solid stylus pen): the font is the user's own monoline handwriting, so `skeletonOf(text, alt, o)` renders a word big (~8 px strokes), finds dots (small blobs → pen taps), Zhang–Suen thins it (`thin`) and traces the 1-px centre lines into strokes by crossing number (1 = end, 2 = chain, ≥3 = fork; staircase shortcuts skipped; short fork whiskers pruned; closed loops kept — `simplify` measures from the point when a stroke starts and ends on the same pixel, or every o/0/a bowl vanishes), plus letter `cuts` (font prefix advances snapped to the least-ink column). Cached in em units in `skCache` (per text + face, NOT per size). `writeWord` makes each instance: letters switched to the font's `salt` alternates in short runs, EXCEPT letters in one of the font's joined pairs (`ligPair`: the font has no kerning, so a pair whose shaped width differs from its letters' widths is a ligature — those only form in the first face, and breaking them made the writing look unjoined) (second FontFace `faceAltFamily` with `featureSettings: '"salt" 1'`; runs in one face stay one shaped run so `liga` joins survive; width refit to the laid-out width), per-letter AR(1) moves (`nodeGap` = Rhythm) — x-height, ascender part and descender part scaled separately, width, shear, bob, gap — blended only across a 0.06 em seam. Keep these SMALL (user's real handwriting: consistent size/lean letter to letter, letters never touching; bigger swings read as a scramble — Mess past ~2 only gets sloppier in placement, `kc` caps it), and a no-crowding guard steps the rest of the word right wherever a letter would close ≥35% of the font's gap to its neighbour; a smooth `vnoise` bend (`vShape`) so each copy of a letter has its own curves; stroke ends that stop short/run on (`endShift`); i/j dots (a dot with a stem under it) landing off-centre as tiny flicks (colon/period dots barely move — this font's colon is tall); descenders folded up to `J.dmax` (from `limitDescenders`, the next line's ink tops; measured per run via `J.toItem`, so a denominator's g counts from its own baseline) and ≤0.66 row. Joins (`vJoin` × Mess): a free stroke end low on a letter's right runs on into a free start on the next letter's left in one Bézier (never into punctuation). Letters sit tighter than the font (`o.tight` = 0.025 em × `vTight` per gap, taken out of the laid-out width too; word gaps get +30% to stay clear); the no-crowding guard lets letters touch but not pile up, and splits any push it makes between the spaces before and after the word. `drawPen` strokes it all at exactly the pen width — ONE weight at every word size (only script text under 62% of the section size thins, to ≥72%; bold ×1.2) — the old cap tied to each word's size made every word a different weight, cached per item in `wordCache`. `\mathbb` = left-side strokes copied +0.12 em. Fallback-font symbols (Σ, ∮, Greek) get re-stroked too, so they look handwritten. Never go back to warping word bitmaps. **Pen types** (`opts.nib`, `NIBS`): `solid` (default; drawn straight onto the canvas, opaque, `source-over`) or gel/ballpoint/fountain/pencil, which go through `paintInk` → `finishInk` (grain + flow `NIB_INK`, ragged edges, pressure `J.dim`) and `multiply` blending; fountain = width ∝ |sin(dir − NIB_ANGLE)| (`strokeOutline`). Settings/sections saved before `inkV: 2` (or `digital`) migrate to `solid` (`migrateSection`, mount). `vInk`/`vPress` only affect textured pens. **Messiness is a hand, not jitter.** `layoutSection` runs slow drifts along writing distance t = lineNo·lineWidth + x (`hSize`/`hSlant`/`hGap`) with per-word randomness on top; word gaps close to 55% at most; text words get size, bob and tilt in LAYOUT (`sized:true`; `drawRun` only jitters math runs itself). Each line's baseline is a smooth curve `yAt` (climb/sag habit + per-line slope + a wave every ~`opts.group` words); on ruled/grid/dot paper words are set ON the line like a real hand (seat −0.03 fs; up ≤0.17 fs·Mess, down ≤0.05 fs·Mess; slope/wave/bob a fraction of plain paper's — whole lines sitting 5 px off the dots read as "too low") and **no word may reach the line above's ink**: `placeLine` lowers just that word, at most 0.18 fs (per-item ink rects incl. rotation vs `above` bins; text words report their real letter-by-letter ink via `runRects` from the skeleton (`box.run`), and inline math is no longer one solid box, so a word only steps down when a letter actually meets a subscript) and records actual bottoms in `prevBot`; a text line may snap one row closer than full clearance (−0.4 fs) since colliding words get lowered — display rows keep full clearance. Margin wander is small (±4 px·Mess). Slant drift rides on the item as `sl` → `J.sl`. `shapeMess` = k^0.8 past 1. Cramped last word squeezes its space; `vOops` (default 0) adds struck-out false starts (`struckBox`). **Knobs** (⚙ popover, `MESS_VARS`/`MESS_DEFAULTS`): `lean`, `gap`; Ink: `vInk`, `vPress`; Letters (×Mess): `vShape`, `vAlt` (0–1, ×min(1, Mess)), `vLetter`, `vLetterW` (letter spacing), `vWave` (bob), `nodeGap` (Rhythm); Words: `vSlant`, `vSize`, `vSpace`, `vBase`, `vTilt`, `vOops`; Lines: `vDrift`, `vWob`. Text-word size is quantized to 2% in layout; the box reports nominal h/d. **Sections:** ✓ Commit (Ctrl+Enter) freezes the editor text + its section settings (`SECTION_KEYS`) into localStorage `engorg_handwriter_sections`; `layout(sections)` flows committed sections then the draft onto the same pages (paper/page colour/font are page-wide); Edit pulls the last one back. **Long display rows are never shrunk with their block:** `displayBoxes` + `breakAtoms` carry over-wide rows onto continuation lines (only before a top-level +/−/relation/\quad, never inside brackets). `splitTop` must skip a nested `\begin{name}`'s own braces. Baselines snap to the ruled lines. Export PDF (pdf-lib) / per-page Copy + PNG (optional ink-only crop) via `api.handwriter.save`. Options in `settings.handwriter` (device-local), draft in localStorage. Preview canvases render at the screen's pixel density (`previewK`), since a 1.25× canvas upscaled on a 2× screen made pen lines look uneven. ## Ecosystem (`ecosystem.js`) — the "branched view"

- **Tree is structure only:** workspace → projects → categories/deliverable buckets → hand-attached species. **Bulk data is NOT branches** — tasks/events/purchases/todos are `items` on their bucket node (count badge) shown in a hover list widget (`openListPopup`, `.eco-list` inside `.eco-root`; clicking a task fires `edit-note`).
- **Hand-attached species are nodes:** folders, files, CAD models (live Three.js slide-in via `window.CadViewer`), links, notes, sub-branches, live utility instances (`window.openEngineeringUtility`).
- **Progressive disclosure:** default shows only projects (`isOpen()` — only `root` open); deeper opens when pinned or on the cursor's focus path. Big fans cluster into **"+N more"** nodes (`CAP`).
- **Cursor-steered nav** (`steerTick`, rAF): hover expands a branch; if the bloom overflows (`allVisibleInView`) the camera eases to fit (`camTarget`/`easeCamera`); leaving all branches collapses + recenters. Toggle via 🧭. Ease speed: Settings → General → "Ecosystem transitions" → `settings.ecosystem.easeSpeed` (`EASE` map).
- **Layout is cached & stable** (`placed`) — expanding one branch never reflows others; children fan outward across three staggered rings. Node size by contents (`nodeScale` → `--eco-scale`); depth-of-field blur off the focused spine (`updateTiers`, `.tier-mid`/`.tier-bg`).
- **Interaction:** drag to move, drop onto a node to re-parent, hover "+", right-click-at-cursor menus, double-click to open.
- **Lenses** (`LENSES`; right-click project → Group by Discipline/Phase/Status/Priority/Timeline/Categories) re-bucket tasks via `disciplineBucket`/`phaseBucket`/`dueBucket`/`taskBucket`; stored per project in `settings.ecosystem.lens`.
- **Suggestions** (`computeSuggestions`, 💡 badge; cached, `bustCache` on data change): overdue focus blocks, deadline protection, WIP trims, V-model phase gaps + next-phase ideas (`NEXT_TASKS`/`PHASE_ORDER`), utility hookups, stale nudges, WBS breakdown, intent-mined tasks (`INTENT_RE`). Calibrated by `computeInsights` (cycle-time median/mean/p90 by category/project/priority, velocity, weekday rhythm, keyword→duration, `estimate(task)`), which also powers the 📊 Insights panel (`openInsightsPanel`).
